# @superinstance/quilt-canon-cli

A unified CLI for the Live Canon (https://live-canon.superinstance.dev).

```bash
npx @superinstance/quilt-canon-cli claim "trust ladder"
npx @superinstance/quilt-canon-cli drill "Mudra vessel bridge"
npx @superinstance/quilt-canon-cli hash
npx @superinstance/quilt-canon-cli count
npx @superinstance/quilt-canon-cli graph 470 2
npx @superinstance/quilt-canon-cli paper 470
```

Wraps `@superinstance/canon-claim`, `@superinstance/canon-hash`, and `@superinstance/canon-graph`.
